⚡ create-ln-app

Make a Lightning app with one command. Get a local regtest network that is ready to use.

npx create-ln-app my-lapp
cd my-lapp
npm run dev

Then open http://localhost:5173 and pay your first invoice.

What you get

  • Bitcoin Core and LND, Core Lightning, or Eclair nodes on regtest, funded and ready. The default is 3 LND nodes. Add --nodes 5 to get 5 nodes (2 to 10). Add --impl cln to get Core Lightning nodes, or --impl eclair to get Eclair nodes.
  • An API server that holds the macaroons and TLS certs. No secret goes to the browser.
  • An example React app: connect a peer, open a channel, make an invoice, and pay it. The default is TypeScript. Add --template react to get JavaScript, or --template next-ts to get Next.js.

What you need

  • Node.js 24 or later.
  • Docker with Docker Compose v2.
